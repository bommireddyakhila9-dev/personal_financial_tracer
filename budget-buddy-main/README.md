# Budget Buddy

Project is now split into separate folders:

- `frontend/`: Vite + React app
- `backend/`: Express API + Supabase access

## Structure

```text
budget-buddy-main/
  frontend/
  backend/
```

## Run Frontend

```bash
cd frontend
npm install
npm run dev
```

## Run Backend

```bash
cd backend
npm install
npm run dev
```

## Supabase Schema

Run:

- [`backend/db/supabase-schema.sql`](./backend/db/supabase-schema.sql)

in your Supabase SQL editor.
